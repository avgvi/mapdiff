---
title: Keys
description: Every key and mouse action on the map.
---

| Key | Does |
|---|---|
| Drag, scroll, arrow keys | Move the map |
| Pinch, Ctrl or Cmd with scroll, `+` `-` | Zoom |
| `0` or `F` | Show the whole map |
| `1` `2` `3` `4` | Level: architecture, package, module, code |
| `/` or Cmd-K | Find a function, type or file |
| Click | Select a box |
| Double-click a title, or `T` | Trace |
| `[` `]` | Back and forward through what was selected |
| Esc | Clear the selection, close a panel |

With a change drawn on the map:

| Key | Does |
|---|---|
| `N` or `J` | Next change |
| `P` or `K` | Previous change |
| `R` | Mark the change reviewed, or unmark it |
| `D` | Hide or show the before and after |
